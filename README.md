# AI Resume Screening System

## Overview
This project is an AI-based resume screening system that evaluates and ranks candidates based on job descriptions using NLP techniques.

## Features
- Multi-resume upload
- Candidate ranking system
- Skill extraction and missing skill detection
- Selection decision (Selected / Not Selected)

## Tech Stack
- Python
- Streamlit
- Scikit-learn
- PyPDF2

## How to Run
pip install -r requirements.txt  
streamlit run app.py
